Frequently asked questions

What image formats can I use as frames?
JPEG and PNG. For best results, all images should be the same dimensions.
How do I control animation speed?
Set the frame delay in milliseconds. 100 ms = 10 fps (standard). 50 ms = 20 fps (fast). 200 ms = 5 fps (slow).
Is there a limit on the number of frames?
No hard limit. More frames produce a larger GIF and slower processing. For web use, aim for under 50 frames if possible.
Can I reorder frames?
Yes — drag frames to reorder them before creating the GIF.
Why does my GIF look different from the source images?
GIF supports only 256 colours per frame. Images with smooth gradients or photos will show some colour banding — this is a fundamental limitation of the GIF format.

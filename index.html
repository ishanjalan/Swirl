Frequently asked questions

What GIF tools does Swirl include?
Video to GIF, GIF from images, optimise, resize, crop, reverse, adjust speed, and add text — 8 tools in total, all browser-based.
Are there file size limits?
No upload means no server-side limits. Processing runs in your browser using WebAssembly. Very large GIFs may take longer on slower devices.
Can I convert a video to a GIF?
Yes — Swirl's Video to GIF tool supports MP4, WebM, and MOV input. Trim the clip, set frame rate and dimensions, then download.
Why are GIFs larger than videos?
GIF is a 1987 format limited to 256 colours per frame and no inter-frame compression. Use WebP animations for modern browsers if file size is critical.
Is Swirl free to use?
Yes, completely free with no account required. Open source on GitHub.

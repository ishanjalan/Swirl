Frequently asked questions

Is the text applied to all frames?
Yes — the text overlay is applied to every frame of the animation consistently.
What fonts are available?
System fonts — sans-serif, serif, and monospace. Custom font upload is not yet supported.
Can I position the text anywhere?
Choose from preset positions (top, centre, bottom) and adjust the offset to fine-tune placement.
Does adding text increase file size?
Yes, slightly — each frame has additional pixel data where the text is rendered.
Can I add a background behind the text to improve readability?
Yes — an optional semi-transparent background box makes text legible over any image content.
